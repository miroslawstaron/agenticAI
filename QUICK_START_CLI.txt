================================================================================
PARAMETERS REFERENCE
================================================================================

BATCH FILE: test-swe-bench.bat [tasks] [server] [model]

  tasks    (optional) Number of tasks or "all"
           Default: 10
           Examples: 5, 20, 50, all

  server   (optional) LLM server URL
           Default: http://lazythought.cse.chalmers.se:80
           Examples: http://localhost:8000, http://server:8080

  model    (optional) Model name
           Default: gpt-oss:20b
           Examples: gpt-4, claude-opus, llama-2

================================================================================
POWERSHELL PARAMETERS: test-swe-bench.ps1 [options]

  -Tasks [value]         Number of tasks or "All" (default: 10)
  -Server [url]          Server URL (default: http://lazythought.cse.chalmers.se:80)
  -Model [name]          Model name (default: gpt-oss:20b)
  -OutputDir [path]      Output directory (default: ./swe_bench_results)
  -SkipDownload          Skip dataset download
  -ShowLogs              Show detailed logs
  -ParallelWorkers [n]   Number of workers (experimental)

Examples:
  .\test-swe-bench.ps1
  .\test-swe-bench.ps1 -Tasks All
  .\test-swe-bench.ps1 -Tasks 50 -ShowLogs
  .\test-swe-bench.ps1 -Tasks 30 -Server "http://localhost:8000" -Model "gpt-4"

================================================================================
TROUBLESHOOTING
================================================================================

PowerShell execution policy error:
  powershell -ExecutionPolicy Bypass -File test-swe-bench.ps1

Python not found:
  Make sure Python is installed and in your PATH
  Test: python --version

Server connection error:
  Verify server is running: http://lazythought.cse.chalmers.se:80
  Check your network connection
  Try a different server

Timeout errors:
  Run fewer tasks: test-swe-bench.bat 5
  Check server performance
  Increase timeout settings
